# Kimi CLI

极简的命令行工具，通过 stdin/stdout 与 kimi.com 交互。

## 功能特性

- ✅ **Unix 哲学**：stdin 输入，stdout 输出
- ✅ **多轮对话**：会话状态自动持久化
- ✅ **微信登录**：二维码通过邮件发送，手机扫码
- ✅ **自动检测**：扫码后自动检测登录状态，无需按回车
- ✅ **JSON 输出**：结构化数据便于程序处理

## 快速开始

### 1. 安装依赖

```bash
pip3 install playwright
playwright install chromium
```

### 2. 配置邮箱授权码

创建配置文件 `~/.kimi_cli_config.json`：

```json
{
    "email_password": "你的163邮箱授权码"
}
```

> 注意：不是邮箱密码，而是 SMTP 授权码。在 163 邮箱设置中开启 SMTP 并获取授权码。

### 3. 使用方法

```bash
# 方式1：管道输入
echo "你好" | python3 kimi.py

# 方式2：使用包装脚本
./kimi "请介绍一下你自己"
```

### 4. 首次使用流程

1. 运行命令后，会自动截取 Kimi 登录二维码
2. 二维码通过邮件发送到 zzm9981@163.com
3. 在手机上打开邮件，用微信扫描二维码
4. **无需按回车**，程序会自动检测扫码成功
5. 程序自动关闭广告弹窗，发送消息，获取回复
6. 登录状态会自动保存，下次无需重复扫码

## 注意事项

- 首次使用需要配置邮箱授权码
- 扫码后程序会自动检测（等待最多120秒）
- 登录状态会自动保存，下次无需重复扫码
- 工具使用 headless 浏览器运行

## 工作原理

1. 访问 kimi.com
2. 检测到需要登录时，截取二维码
3. 通过邮件发送二维码图片
4. 轮询检测登录状态（每5秒检测一次，最多120秒）
5. 登录成功后自动关闭广告弹窗
6. 发送用户问题到 Kimi
7. 等待回复生成完成
8. 提取并返回回复内容
